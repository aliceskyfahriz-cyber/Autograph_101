# AutographFJ v1 — arsip proyek

Folder ini berisi dokumentasi dan catatan progres proyek AutoGraph FJ v1
(aplikasi monitoring poin teknisi IndiHome, Capstone Fahriz).

Kode sumber (frontend Vue 3 + backend server.js) saat ini berada di PC Fahriz
dan belum diunggah ke repo ini. Status proyek: berhenti di titik aman,
menunggu instruksi lanjut STEP 6E dari Fahriz.

Isi arsip:
- `PROGRES.md` — checkpoint progres terakhir
- `RINGKASAN-CHAT-1.md` — ringkasan percakapan desain/pengembangan
- `SUMBER.md` — daftar sumber
- `poster/POSTER.md` — catatan poster proyek
