# AutoGraph FJ — Technician Point Monitoring System

Prototype Capstone berbasis Vue 3 + Vite.

Fitur: dashboard poin, input pekerjaan, master pekerjaan/bobot poin, target, riwayat, laporan, export CSV, localStorage, responsive UI, login demo.

> Bobot poin pada demo adalah DATA CONTOH. Ganti melalui Master Pekerjaan sesuai data yang memang boleh digunakan. Hasil aplikasi bukan angka penggajian resmi.

## Jalankan
```bash
npm install
npm run dev
```
Buka http://localhost:5173/
